# Changelog

## 0.9.0

First public test release.

- Hammer + selected piece + **N** pulls one full set of the piece's materials from nearby CraftyBoxes containers.
- All-or-nothing: refuses (with a message) if anything is missing, the set would over-encumber you, or it doesn't fit.
- `FullSet` (default) and `TopUp` pull modes.
- Configurable key, optional gamepad button, allowed tools and message positions.
- "Pull mats" row in the build-mode key hints.
- Optional server install syncs the gameplay settings; never blocks joining.
